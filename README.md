Data Analytics Internship – Task 5 (Excel Data Analysis)

This repository contains my submission for Task 5 of the Data Analytics Internship.

Dataset - Cleaned Sample Superstore Dataset

Objective - The objective was to analyze a structured dataset using Excel formulas, sorting, filtering, PivotTables, and basic KPIs.

Tools Used
1. Microsoft Excel
2. Sample Superstore Cleaned Dataset
3. GitHub

Workbook Components
1. Raw Data sheet containing the cleaned Sample Superstore dataset
2. Analysis sheet containing formulas and KPI calculations
3. Summary sheet containing PivotTables and key findings

KPIs Created
1. Total Sales
2. Total Profit
3. Total Quantity
4. Average Discount

Analysis Performed
1. Reviewed the cleaned Sample Superstore dataset
2. Used Excel formulas to calculate basic KPIs
3. Used SUMIFS to analyze sales and profit by category and region
4. Used sorting and filtering to work with the dataset
5. Created a PivotTable for Sales by Category
6. Created a PivotTable for Sales by Region
7. Created a PivotTable for Profit by Category
8. Created a PivotTable for Profit by Region
9. Summarized the key findings from the analysis

Key Findings
The analysis shows that Technology is the strongest category in terms of sales and profit, while Furniture contributes comparatively less profit. The West region generates the highest sales among the regions, while regional profit performance varies. Overall, the analysis shows that sales volume alone does not always indicate higher profitability, so both sales and profit should be considered when evaluating business performance.
